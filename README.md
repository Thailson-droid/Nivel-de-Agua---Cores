# 💧 Controle de Níveis de Água

## 📋 Sobre o projeto

Este projeto simula um sistema de monitoramento do nível de água de um reservatório.

O programa é executado no terminal e solicita ao usuário um nível de água entre `1` e `5`. De acordo com o nível informado, o sistema exibe uma mensagem com uma cor específica utilizando a biblioteca `Colorama`.

## 🎯 Objetivos

- Utilizar uma lista em Python;
- Criar e utilizar funções;
- Receber dados de entrada do usuário;
- Validar os dados informados;
- Exibir mensagens coloridas no terminal;
- Restaurar o estilo padrão do terminal após a exibição.

## 📊 Níveis do reservatório

| Nível | Situação | Cor |
|---|---|---|
| 1 | Muito baixo, crítico | Vermelho |
| 2 | Baixo | Amarelo |
| 3 | Médio | Verde |
| 4 | Alto | Ciano |
| 5 | Muito alto, alerta | Azul |

## 🛠️ Tecnologias utilizadas

- Python 3
- Biblioteca Colorama
